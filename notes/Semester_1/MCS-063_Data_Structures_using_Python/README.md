# MCS-063: Data Structures using Python
**Semester:** Semester 1 | **Credits:** 4 (Theory)

### 📋 Course Overview
Algorithmic analysis, recursion, linear and tree structures, priority queues, hash tables, sorting, and memory management in Python.
