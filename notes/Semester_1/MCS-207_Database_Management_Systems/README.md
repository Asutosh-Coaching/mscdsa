# MCS-207: Database Management Systems
**Semester:** Semester 1 | **Credits:** 4 (Theory)

### 📋 Course Overview
Relational algebra, ER modeling, SQL optimization, normalization (1NF-BCNF), ACID concurrency, recovery, and NoSQL engines.
