# MCS-066: Mathematical Foundations - II
**Semester:** Semester 2 | **Credits:** 4 (Theory)

### 📋 Course Overview
Rigorous probability theory, random variables, probability distributions, sampling, parameter estimation, hypothesis testing, ANOVA, and convex optimization.
