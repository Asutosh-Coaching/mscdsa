# MCS-068: Predictive Data Analysis
**Semester:** Semester 2 | **Credits:** 4 (Theory)

### 📋 Course Overview
Descriptive, diagnostic, and predictive modeling, multiple regression, regularization (Ridge/Lasso), classification, clustering, PCA, and R programming.
