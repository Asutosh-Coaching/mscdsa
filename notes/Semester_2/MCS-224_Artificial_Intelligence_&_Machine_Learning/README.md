# MCS-224: Artificial Intelligence & Machine Learning
**Semester:** Semester 2 | **Credits:** 4 (Theory)

### 📋 Course Overview
State-space search (A*, Minimax), First-Order Logic, probabilistic reasoning, fuzzy sets, supervised learning, neural networks, and deep learning backpropagation.
