marks. Rest 20 marks are for viva voce. All algorithms should be written nearer to Python

explanations, if necessary.

Q2: What is a Tree ? How does it differ from a Binary Tree ? Explain the process of converting a 
Tree into a Binary Tree.                                        (20 Marks) 
 
Q3: Explain built in sorting functions of Python with examples.                (20 Marks) 
  
Q4: What is a Minimum Cost Spanning Tree? Explain with an example.   (20 Marks)
